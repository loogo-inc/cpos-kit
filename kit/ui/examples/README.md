# 見本 (規約どおりの画面)

ブラウザでそのまま開ける (サーバは要らない)。**画面を作るときはこの HTML を真似る。**
規約の本文は AGENTS.md の「画面の規約 (cpos-kit)」、スタイルは `../cpos-ui.css`。

| 見本 | 何の例か | 見どころ (決めの番号) |
|---|---|---|
| `today.html` | 最初の画面 (今日やること) | 13 行き先は 5 つまで・いまいる所が分かる / 14 右上に自分とログアウト / 3 検索は即時 / 9 状態は色 + 文字 / 11 0 件は理由 + 次の一手 |
| `user.html` | 1 件の詳細 (利用者) | 12 値が無い項目は「未設定」/ 1 意思決定は右 / 8 取り消せない操作だけ確認・ボタンは動詞 / 一覧へ戻る |
| `settings.html` | 設定と自分 | 15 アプリはアプリ固有の設定しか持たない / 14 ログアウトは CPOS に返す / 7 保存バー |
| `users.html` | 一覧 + その場で入力 (雛形が出す画面) | 5 表は狭い幅でカードになる / 7 保存バー / 11 0 件 |
| `record.html` | 1 件の入力 | 5 必須は赤い「必須」の文字 / 6 誤りは欄の直下 / 8 削除の確認 |

行き先 (`.cpos-nav`) は狭い幅では画面の下、900px 以上では左に出る。HTML は同じで CSS が切り替える。

## 事業所を出す画面・出さない画面 (決め 10 / 10b)

- 出す: その画面が**事業所単位のデータ**を出すとき (`today.html` 今日の訪問、`user.html` 利用者、`users.html` 一覧)。取り違えると別の事業所の個人情報を扱うため、スクロールしても見える位置に置く。
- 出さない: **事業所に関係ない画面** (`settings.html` 自分の設定。法人単位 `{ scope: 'organization' }` のデータ、お知らせなども同じ)。代わりに `.cpos-scope` で「自分だけの設定」「法人全体」と範囲を書く。
